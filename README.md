# RH Conseil 71

Refonte moderne du site vitrine RH Conseil 71, développée en React + TypeScript avec Vite.

## Objectifs

- conserver l'identité multicolore historique de RH Conseil 71 ;
- moderniser la hiérarchie visuelle et l'expérience de navigation ;
- présenter clairement toutes les expertises du cabinet ;
- valoriser la formation et la certification Qualiopi ;
- distinguer les parcours entreprises, particuliers et candidats ;
- proposer des animations professionnelles sans nuire à la lisibilité ;
- offrir une expérience responsive sur ordinateur, tablette et mobile.

## Stack

- React
- TypeScript
- Vite
- Framer Motion
- Lucide React

## Développement

Installer les dépendances :

    npm install

Lancer le serveur de développement :

    npm run dev

Créer la version de production :

    npm run build

Prévisualiser la version de production :

    npm run preview

## Contenu

Le contenu reprend et réorganise les principales informations publiques du site RH Conseil 71 : accompagnement et développement RH, formations, RSE, social / RGPD, management des carrières, QHSE, QVCT, recrutement, accompagnement des particuliers, certification Qualiopi et coordonnées du cabinet.

Le formulaire de contact fonctionne sans serveur : il prépare un e-mail à destination de `accueil@rhconseil71.com` dans le logiciel de messagerie du visiteur.
